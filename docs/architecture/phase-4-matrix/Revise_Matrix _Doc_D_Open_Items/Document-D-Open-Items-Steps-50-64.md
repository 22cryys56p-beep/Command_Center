# CC Phase 4 Matrix — Document D: Open Items (OPEN — Decision Required)

**Scope covered:** Categories 50–64

---

### Category 55 — Security, Privacy & Trust Boundaries

- P4-R698 — The need for resource/project access classification is sound, but the actual classification model is not yet decided. The proposed `Public / Internal / Private / Restricted` vocabulary is an example, not an approved taxonomy.

### Category 61 — Notifications, Signals & Attention

- Exact escalation thresholds for External Cutoffs (e.g., the specific day-counts at which Attention should escalate from Informational → Attention → Priority → Urgent → Critical) remain unspecified. The architectural concept — that Hard External Cutoffs generate escalating Attention based on proximity — is sound and retained in Document A; only the numerical thresholds are undecided.

### Category 64 — The Project List

- The complete model separating **Project State** from **Project Visibility** has been identified as a necessary architectural distinction, but its full definition has not yet been established. This is the most significant open item carried out of the Steps 1–64 audit as a whole: it is precisely the question the original Category 65 drift session attempted (and failed) to answer, and it should be resolved deliberately — grounded in the single-tier status model confirmed in the Categories 43–49 chunk — rather than assumed by whatever eventually replaces or corrects Category 65.
